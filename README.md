# TrendPulse Daily

AI-powered daily publication covering AI, technology, business, India, and world affairs.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4
- Supabase PostgreSQL/Auth/Storage
- Vercel deployment
- Scheduled research and hybrid publishing pipeline

## Local setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000.

## Publishing policy

Low-risk AI, technology, tutorials, and evergreen content may be auto-published after validation. Current affairs, politics, emergencies, health, finance, legal topics, and unverified claims require admin approval.
